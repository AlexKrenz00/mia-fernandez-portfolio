# Portafolio de Alexis Krenz

Portafolio profesional de diseño y desarrollo web. Presenta proyectos reales, servicios, proceso de trabajo y canales de contacto para clientes que necesitan invitaciones digitales, páginas para negocios o soluciones web personalizadas.

## Proyectos destacados

- Invitación digital de XV años de Danna.
- Invitación digital de XV años de Lilian.
- Thompson Medical System, sistema web de gestión clínica en desarrollo.

## Tecnologías

- React 19
- TypeScript
- Vite y Vinext
- CSS responsive
- Cloudflare Workers

## Características

- Diseño adaptable a celulares, tablets y computadoras.
- Presentación interactiva de proyectos publicados.
- Consultas personalizadas mediante WhatsApp.
- Secciones de servicios, proceso y preguntas frecuentes.
- Metadatos para buscadores y vista previa en redes sociales.
- Accesibilidad básica y soporte para reducción de movimiento.

## Ejecutar localmente

Requiere Node.js 22.13 o superior.

```bash
npm install
npm run dev
```

Luego se puede abrir `http://localhost:3000`.

## Verificar el proyecto

```bash
npm test
```
